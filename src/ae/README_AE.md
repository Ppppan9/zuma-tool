# 祖玛核玩工具 · AE 工程导出说明

1. 解压 zip，After Effects（2020+）→ 文件 → 脚本 → 运行脚本文件 → 选 `build_ae_project.jsx`（需与 `timeline.json`、`assets/`、`audio/` 同目录）。
2. 脚本会新建工程：文件夹「祖玛_AE工程」，主合成「主合成_祖玛」（尺寸 = 导出时画布的可视区域，帧率见 timeline.json）。
3. 图层：背景（遗迹 / 灰色主题，切换主题时为两段）→ 石青蛙（旋转关键帧 = 瞄准方向）→ 每颗球一个图层（位置 / 缩放关键帧，进洞时缩小）→ 口中球 → 消除特效（白闪 / 彩色光晕 / 溅射 / 碎石 / 尘土，光晕为“相加”混合）→ 失败模糊（调整图层 + 高斯模糊关键帧）→ 免责声明 → FAIL 徽章（缩放 + 旋转弹出）→ 结束页 → 手指。
4. 音频：`audio/mix.wav` 混合音轨 + 预合成「音效_逐事件」（每次发射 / 插入 / 消除 / 吸入 / 失败各一个图层），主合成上有对应标记。

已知限制（如实说明）：
- 球与青蛙为离屏 three.js 渲染的静态 PNG（含烘焙阴影），AE 里不会出现球体“滚动”的花纹旋转；青蛙图层旋转时烘焙阴影会跟着转。
- 背景模糊用 AE 高斯模糊模拟页面 canvas blur，强度接近但不完全一致。
